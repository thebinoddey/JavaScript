# What is DOM?

DOM stands for **Document Object Model**.

It is a programming interface that represents an __HTML document as a hierarchical tree of objects (nodes)__.

When a browser loads an HTML document, it parses the HTML and creates a DOM tree. JavaScript can access and manipulate this tree.


## Important terms
- Document: Entire HTML document
- Node: Any object in the DOM tree
- Element: HTML element such as div, p, h1
- Attribute: HTML properties such as id, class, src
- Text node: Text inside an element
- Parent: Node containing another node
- Child: Node inside another node
- Sibling: Nodes sharing the same parent
